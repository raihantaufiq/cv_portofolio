Automation Data Scraping

Sistem otomasi pengumpulan dan pemrosesan data produk pada web. Memahami struktur web yang datanya akan di scraping (Web link: https://fashion-studio.dicoding.dev/). Melakukan Extract data menggunakan sistem yang diprogram dengan Python, kemudian Transform data dengan melakukan data cleaning dan processing menggunakan Pandas yang diintegrasikan dengan program Python. Melakukan Load dengan menyimpan hasil data dalam format csv agar bisa digunakan lebih lanjut.
